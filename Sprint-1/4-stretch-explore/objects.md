Answer the following questions:

What does `console` store?
console stores multiple functions like debug, log, profile, trace, warn etc

What does the syntax `console.log` or `console.assert` mean? In particular, what does the `.` mean?
This syntax means that we are invoking functions "log" and "assert" from the object "console".
The dot operator lets us invoke the functions associated with the object
